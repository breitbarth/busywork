Each project explanation covers **Process, Problem, Example, Impact, Confirm, and Relevant features**. [Use the same template](PROJECT_TEMPLATE.md) when adding a project: describe the benefit, show a concrete situation, and say what evidence confirms the result.

## Read the status before judging the work

Learning material demonstrates an area of study. A prototype demonstrates a working slice. A validated result needs an appropriate test, observation, or study. Repository ownership alone does not establish original authorship; upstream workshop credits and fork attribution remain visible.

This repository provides navigation and documentation. It does not contain a standalone application. [Visit the profile](https://github.com/breitbarth) for the professional introduction.
