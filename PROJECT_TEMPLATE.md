# Project name

One sentence describing who it helps and the result it supports.

**Stage:** concept / specification / working prototype / validated pilot / production. Choose the stage supported by the evidence and link the current artifact.

## Process

Explain the steps from input or starting situation to output. Say which steps exist and which are proposed. Include setup or usage instructions when an artifact can run.

## Problem

Describe who encounters the problem, when it happens, and why it matters. Separate a confirmed need from a hypothesis awaiting discovery.

## Example

Walk through one concrete situation: input, action, and expected or observed output. Label synthetic data and hypothetical interactions. Link a demo or artifact where available.

## Impact

State the practical difference the project could make. Separate demonstrated results from intended benefits. Use numbers only with a source, baseline, and appropriate scope.

## Confirm

**Fit question:** What would establish that this solves the user's problem?

**Evidence:** What was checked, when, and with what result? Link the test, observation, review, or study. State what that evidence does not establish. If nothing has been checked yet, define the next acceptance result.
